# ExplainerPFN

ExplainerPFN is an explainability method based on TabPFN (a Prior-Fitted
Network for tabular data). The repo includes training code, inference
pipelines, visualization tools, and uses SHAP as the ground truth for model
interpretability. The goal of this project is to provide a fast and efficient
way to feature contributions via zero-shot predictions without access to the
original prediction model.
